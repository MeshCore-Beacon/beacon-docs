# BEACON Mobile Support

BEACON Mobile is the iOS and Android client for Beacon, the real-time MeshCore
packet analyzer.

## Getting started

The app connects to the public Beacon server at `dev.meshcore.ca` out of the
box, so live packets, the map and analytics appear right away. To use a
different Beacon server, open **Settings → Servers** and add its address.
Running your own server is covered in the
[deployment guide](https://github.com/MeshCore-Beacon/beacon-docs#readme).

## Beta testing

- **iPhone and iPad:** join through the public TestFlight link and send feedback
  from the TestFlight app (take a screenshot in BEACON to attach it).
- **Android:** join the Google Play testing program from the opt-in link, then
  leave feedback on the app's Play page.

## Report a problem or request a feature

[Open an issue on GitHub](https://github.com/MeshCore-Beacon/beacon-flutter-app/issues)
with your device model, OS version, the app version (Settings → About) and what
happened.
